# Changelog

All notable changes to JecBridge Desktop are documented here.

## [2.0.0] - 2026-10-31

### Added
- Global My Skills library for reusable AI instructions.
- Create, import, edit, and delete skills from the desktop app.
- Assign shared skills to individual projects.
- Project enable/disable switch and command permission controls.
- GitHub Releases-based update checks and in-app update download/install flow.

### Improved
- Redesigned skill creation and editing experience.
- Clearer project management controls and status feedback.
- Settings page with application and system information.
- Windows installer branding and packaging workflow.

### Notes
- Windows x64 is the packaged release target.
- Existing local project data and skills remain in the user's application data directory during upgrades.
